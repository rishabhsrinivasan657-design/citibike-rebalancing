# Definition

While a station is empty, nobody can take a bike, so the data shows no departures
even though people wanted bikes. While a station is empty (or full), the project adds
that station's usual departures (or returns) for the day type and hour, from the
[station-hour profile](/glossary/station-hour-profile.md).
