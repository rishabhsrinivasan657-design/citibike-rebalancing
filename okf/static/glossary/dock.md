# Definition

A slot that locks one bike. Free docks are where riders can return a bike; when a
station has no free docks it is **full** and riders must go elsewhere. Disabled docks
are out of service. See `num_docks_available` in
[fct_station_minute](/tables/fct_station_minute.md).
